# 나눔스퀘어 (NanumSquare)

사용자가 제공한 `nanum-square.zip`에서 TTF Light·Regular·Bold·ExtraBold 원본 4개를 선택했습니다.
압축 파일의 SHA-256은 `8a9f4ce7638feb73cde7adfebc2ec4f2dcee4bcebbb07e0fa1aae02f7340f3e8`입니다.
AC 별도 파일과 OTF 중복본은 배포에 포함하지 않습니다. 원본 파일은 수정하지 않았습니다.

글꼴은 WPF 리소스로 포함하므로 별도 Windows 글꼴 설치나 실행 중 네트워크 다운로드가 필요하지 않습니다.
메인 창·종료 확인·YouTube 창의 앱 소유 컨트롤에 같은 글꼴을 사용합니다.
